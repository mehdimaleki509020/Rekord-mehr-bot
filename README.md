# Rekord Mehr Bot

ربات «رکورد غیربرقی مهر» برای گروه بله، روی Cloudflare Workers + D1.

## قابلیت‌ها

- ۹۲ فروشنده و تارگت‌های نهایی مهر داخل پروژه ثبت شده‌اند.
- `وضعیت من`: فروش، رشد، پاداش فعلی و فاصله تا پله بعدی.
- `وضعیت شعبه [نام شعبه]`: جمع فروش و وضعیت تیم شعبه.
- `رتبه‌بندی`: رتبه رشد فروشندگان.
- ثبت‌نام فروشنده با نام و اتصال به شناسه بله.
- دریافت فایل خام `SalesReport.xlsb` فقط در چت خصوصی ربات.
- پردازش خودکار فایل خام با GitHub Actions و ذخیره نتیجه در D1.

## معماری

Cloudflare Worker کارهای سبک ربات، Webhook و D1 را انجام می‌دهد. پردازش فایل XLSB به GitHub Actions سپرده شده تا روی پلن رایگان Worker نیاز به پردازش سنگین نباشد. ارتباط پردازشگر GitHub با Worker با GitHub OIDC امضاشده انجام می‌شود و توکن بله داخل Cloudflare باقی می‌ماند.

## تنظیمات اجرایی

در Cloudflare:
- Secret توکن بله با یکی از نام‌های `BALE_TOKEN`، `BALE_BOT_TOKEN` یا `BOT_TOKEN`.
- D1 binding با نام `DB`.

در GitHub:
- Actions باید فعال باشد.
- Repository variable با نام `REKORD_WORKER_URL` باید آدرس کامل Worker را داشته باشد.

پس از Deploy، یک‌بار مسیر `/setup` روی Worker فراخوانی می‌شود تا Webhook بله روی `/webhook` تنظیم شود.
